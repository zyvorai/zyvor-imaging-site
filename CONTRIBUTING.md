# Contributing

Thank you for looking at Zyvor Imaging. This repository is the **public website and evaluation releases**; the product source is private, and the website files here are generated from it. That shapes how you can help.

## What helps most

- **Feedback from an evaluation.** What confused you, what was slow, what you expected and did not find. Short and honest is perfect. Use the **Feedback** issue form, or email [sales@zyvor.dev](mailto:sales@zyvor.dev).
- **Reports that something does not work.** Use the **Bug report** issue form and say which path you used (demo link, Mac app, laptop zip, cluster) and the version.
- **Security reports** go to [security@zyvor.dev](mailto:security@zyvor.dev), never into a public issue. See [SECURITY.md](SECURITY.md).

## Please never include

**Patient data, real images or credentials.** Not in an issue, not in a screenshot, not in a log excerpt. Zyvor Imaging is an engineering release for synthetic data only. If you are not sure whether something is safe to share, leave it out.

## Pull requests

Pull requests are not accepted for the website files, because they are regenerated from the product repository and a hand edit here would be overwritten on the next publish. If you spot a mistake on the site or in these docs, open an issue and we will fix it at the source.
